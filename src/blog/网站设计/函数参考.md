源码依据：项目已安装的 Laravel 12.68.0 和 PHP 8.2.12。每个条目给出函数作用及参数表；门面追踪到实际实现。`prefix`、`middleware` 是动态方法，实际分发机制在说明中列出。

### md5

计算字符串的 MD5 摘要；项目用于保存/比对密码、根据用户名生成 token，以及 Seeder 的初始密码。该函数是 PHP 内置实现，vendor 没有它的 PHP 定义文件。

| 参数 | 默认值 | 含义与作用 |
| --- | --- | --- |
| `$string` | 无（必传） | 原始密码或用户名；生成密码摘要或登录 token。 |
| `$binary` | `false` | 是否返回 16 字节二进制摘要；默认 false，项目得到 32 位十六进制字符串。 |
