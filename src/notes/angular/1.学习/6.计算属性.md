和 `vue` 一样, 我们可以使用 `computed` 来创建计算属性。

这个计算属性也一样是无法修改或更新的。而且也自带了缓存，不会因为重复读取出现再次计算的情况。

```ts
import { computed, signal } from '@angular/core'

const firstName = signal('John')
const upperCaseFirstName = computed(() => firstName().toUpperCase())
```
