在 Angular 中, 我们可以使用 `@if` 指令来实现条件渲染。

他的语法和 `laravel` 还是很像的

```html
@if (condition){
  <div>Condition is true</div>
}
@else if (condition2) {
  <div>Condition2 is true</div>
}
@else {
  <div>Condition is false</div>
}
```

## for 循环

此处的 `track` 关键字是用来追踪循环的索引的, 这样可以提高渲染性能。

通常应该是一个数据的唯一标识符, 但是如果没有唯一标识符, 也可以使用 `$index` 来追踪索引, 不过最好不要使用索引值来进行追踪。

```html
@for (item of loginForm.username().errors(); track $index) {
  <p>{{ item }}</p>
}
```
