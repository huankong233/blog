`svelte` 中的派生（derived）是指从一个或多个状态中计算出一个新的状态。派生状态通常用于根据现有状态的变化来动态计算新的值。

类似 `vue` 中的计算属性，派生状态可以帮助我们在组件中更好地管理和组织数据。

```svelte
<script>
	let name = 'Default Name';

  //                       这里不能使用函数, 否则在使用的时候就需要再调用一次
	let full_name = $derived(name + ' Smith');
  let full_name2 = $derived.by(() => {
    return name + ' Johnson';
  });
</script>
```
