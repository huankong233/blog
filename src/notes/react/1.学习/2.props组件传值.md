`props` 是 React 中用于组件之间传递数据的一种机制。通过 `props`，父组件可以向子组件传递数据，从而实现组件之间的通信。

对应到我们的组件中, `props` 就是一个传递给函数的参数

```tsx
function MyComponent({ name }) {
  return <div>{name}</div>
}

function App() {
  return <MyComponent name="Hello, World!" />
}
```
