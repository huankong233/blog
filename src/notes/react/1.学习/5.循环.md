React 中的循环也是和 Vue 不一样的, Vue 中有 `v-for` 来实现循环渲染, 而 React 中没有类似的指令, 只能通过 JavaScript 的数组方法来实现循环渲染。

但是一样也有 `key` 的概念, 也就是在循环渲染的时候, 每个元素都需要有一个唯一的 `key` 来标识, 这样 React 才能高效地更新和渲染组件。

```tsx
function MyComponent({ items }) {
  return (
    <ul>
      {items.map((item, index) => (
        <li key={index}>{item}</li>
      ))}
    </ul>
  )
}
```
